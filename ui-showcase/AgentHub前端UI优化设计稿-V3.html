设计说明 · V3

V3 基于 V2 视觉稿收敛：保留深色侧栏 + 紫色品牌色，但降低渐变与阴影的使用频率，强化页面层级、空状态、操作路径与信息对比度。所有页面、字段、状态仍来自 frontend/src 现有代码的数据模型，未改动任何代码。

本轮收敛要点

  • 页面固定「标题区 / 辅助区 / 内容区」三层结构，主操作始终固定在标题右侧。
  • 侧栏可收缩为图标模式（带 Tooltip），移动端改为抽屉；导航只保留一个激活项。
  • AI 对话空状态升级为工作入口：Agent 简介、能力标签、示例问题、常驻输入框。
  • 首页新增「开始使用 AgentHub」三步引导；有数据时展示最近使用 / 最近对话。
  • 组件规范沉淀：Button / Badge / Card / EmptyState / LoadingState / ConfirmDialog / Toast。
  • 表格重排可扫描列序（状态→对象→耗时→Token→时间→操作），主列表脱离卡片直接落页面背景。
  • 辅助文字对比度上调；新增模块识别色（Agent 紫 / 知识库蓝 / 工具绿 / 执行橙 / 组织灰蓝）。
注意：本稿为视觉概念稿，演示按钮用于切换展示页与触发弹窗/Toast；实际功能以代码为准，后续可据此视觉规范落地到 React 前端。
