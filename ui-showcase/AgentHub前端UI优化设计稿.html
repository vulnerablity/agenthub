优化要点

  • 深色侧栏 + 渐变品牌标识：与浅色内容区形成稳定导航层，激活态用紫罗兰渐变高亮。
  • 概览页升级为工作台：统计卡 + 趋势迷你图 + 最近执行，信息密度提升、一眼可读。
  • 聊天页强化 RAG 引用与工具调用轨迹：来源胶囊、工具卡片、流式打字光标。
  • 执行监控新增链路可视化：LLM / RAG / Tool 步骤横向流水，耗时与 Token 一眼定位。
  • 统一图标语言（内联 SVG）、状态徽章语义色、表格显式列宽、hover 微交互。
注意：本稿为视觉概念稿，交互按钮多用于切换展示页；实际功能以代码为准，后续落地可直接按此视觉规范实施。
