# 需求文档 V1.0

# 1. 项目概述

## 1.1 项目名称

AgentHub

## 1.2 项目定位

AgentHub 是一个面向企业和团队的 AI Agent 管理与运行平台。

平台支持：

*   AI Agent 创建
    
*   Agent 配置管理
    
*   Agent 版本管理
    
*   知识库管理
    
*   RAG 检索增强生成
    
*   Tool Calling 工具调用
    
*   AI 对话
    
*   执行过程监控
    
*   权限管理
    

目标是形成完整 AI 应用工程闭环：

用户 → Agent → Knowledge → RAG → Tool → LLM → Execution Log

# 3. 功能需求

# 3.1 用户认证模块

## 功能描述

实现用户注册、登录、身份认证。

## 功能列表

### 注册

用户输入：

*   邮箱
    
*   用户名
    
*   密码
    

系统：

*   校验邮箱唯一性
    
*   密码加密保存
    
*   创建用户
    

### 登录

输入：

*   邮箱
    
*   密码
    

返回：

*   Access Token
    
*   Refresh Token
    

### 当前用户

获取：

*   用户信息
    
*   所属组织
    
*   权限信息
    

## API

### 用户注册

POST

```plaintext
/api/v1/auth/register

```

Request:

```json
{
  "email":"test@test.com",
  "username":"admin",
  "password":"123456"
}

```

Response:

```json
{
  "id":1,
  "email":"test@test.com"
}

```
---

### 用户登录

POST

```plaintext

```
---

### 获取用户信息

```plaintext

```

# 5. 核心业务流程

## 5.1 用户聊天流程

1.  用户发送问题
    
2.  FastAPI 接收请求
    
3.  加载 Agent 配置
    
4.  查询知识库
    
5.  RAG 检索相关文档
    
6.  调用 Tool（如需要）
    
7.  请求 LLM
    
8.  SSE 返回结果
    
9.  保存消息和执行日志
    

## 5.2 文档处理流程

上传文件：

↓

保存文件

↓

解析文本

↓

Chunk 分割

↓

Embedding

↓

写入 Qdrant

↓

更新文档状态
